# Culinary Book
Jeden z mých největších projektů zatím.

Celkový development trval něco v rozmezí 50-60 hodin.

Stránku jsem se snažil vytvořit bez většího používání AI (žádný vibecoding).

AI bylo použité maximálně v případě vyhledávání funkcí nebo když jsem už fakt nevěděl

## O čem to je?
Tuhle webovku si oblíbí kuchaři nebo každý, kdo rád vaří. Webovka slouží jako zápisník na recepty, ale s funkcemi navíc. Už žádné zapisování do papíru a hledaní celé hodiny jen kvůli jednomu receptu!

## Odkaz na stránku
[culinary-book.vercel.app](https://culinary-book.vercel.app/)

## Funkce stránky
- Přidání receptu
- Kontrola zda uživatel zadal minimální počet znaků
- Prohlédnutí receptu
- Úprava konkrétního receptu
- Smazání receptu
- Filtrace podle názvu receptu
- Filtrace podle kategorie receptu
- Dark mode
- Navigace mezi recepty i podle vyfiltrovaných výsledků
- automatické ukládání dat (local storage)

## Použité technologie
- Next.js
- React
- Tailwind CSS
- TypeScript
